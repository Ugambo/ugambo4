# Explore Katsina

Tourism guide, business directory, booking marketplace and interactive map for Katsina State, Nigeria.
Built on WordPress with a custom plugin (`explore-katsina-core`) and a Kadence child theme (`explore-katsina`).

- Plan: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Progress & how to continue: [HANDOVER.md](HANDOVER.md)
- Setup: `./setup.sh` (needs Docker and Node.js)

- Tests: `./tests/run.sh`
- Brand: Durbar Regalia ([options](docs/brand-options.html))
